Captación y enriquecimiento

1

Descubrir catálogo

{{ 'Activo' if active_jobs['discover'] else 'Disponible' }}

Recorre el catálogo para localizar fichas nuevas, cambios y desapariciones. Es el primer paso del flujo.

Catálogo de origen que se va a recorrer.

Buscar novedades continúa desde la última ficha procesada y es la opción habitual. Barrido completo recorre todo el catálogo desde el principio; úsalo para una revisión a fondo.

2

Enriquecer fichas

{{ 'Activo' if active_jobs['enrich'] else 'Disponible' }}

Descarga la ficha completa de cada edición descubierta: título, año, soporte, bibliotecas y disponibilidad.

Catálogo cuyas fichas se van a enriquecer.

Máximo de fichas que se procesarán en esta ejecución. El resto queda pendiente para la siguiente.

3

Metadatos TMDB

{{ 'Activo' if active_jobs['tmdb'] else 'Disponible' }}

Empareja las ediciones con TMDB y completa póster, país de origen y enlace a la ficha de la película.

Catálogo cuyas fichas se van a sincronizar con TMDB.

Máximo de fichas a sincronizar en esta ejecución. El resto queda pendiente para la siguiente.

Vuelve a consultar TMDB para las fichas que ya tenían metadatos. Consume más tiempo y peticiones.

El límite de intentos por ficha configurado en Configuración también se aplica a esta opción.

Requiere un token de TMDB configurado en Configuración.

Mantenimiento

4

Reindexar

{{ 'Activo' if active_jobs['index'] else 'Disponible' }}

Reconstruye el índice de búsqueda con las ediciones y metadatos ya guardados. No descarga fichas nuevas.

Catálogo cuyo índice se va a reconstruir.

Bibliotecas

Catálogo del que se actualizan las bibliotecas.
